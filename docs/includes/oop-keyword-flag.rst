.. note::

   |keyword| is a keyword only when the |flag| flag is enabled. When the flag
   is not set, |keyword| is an ordinary identifier and may be used as a
   variable or type name, exactly as in standard IEC 61131-3. Pass |flag| to
   enable the object-oriented syntax, or select a dialect that includes it.
   See :doc:`/explanation/enabling-dialects-and-features` for the dialects and
   flags reference.
