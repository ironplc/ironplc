Allow the ``PERSISTENT`` variable qualifier, alone or combined with
``RETAIN`` in either order (``RETAIN PERSISTENT`` or
``PERSISTENT RETAIN``), on ``VAR``, ``VAR_GLOBAL``, ``VAR_INPUT`` and
``VAR_OUTPUT`` blocks. See :doc:`/reference/language/variables/retention`.
This is an extension, not part of the IEC 61131-3 standard.
