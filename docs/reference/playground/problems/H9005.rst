=====
H9005
=====

.. problem-summary:: H9005

The playground compiled your program but could not serialize the resulting
bytecode into an ``.iplc`` container, so no runnable output was produced.

Compilation ends by writing the generated program into a binary container: a
header, a version, the bytecode section, and optional debug information. That
container is what the runtime later loads to execute the program. This code marks
a failure during that write step — the in-memory program was built, but turning
it into container bytes did not complete.

When this happens
=================

This is an **internal error**. Writing a container is expected to always succeed
once a program has compiled, so a failure here indicates a defect in the
compiler's container writer rather than a problem in your IEC 61131-3 source.

How to fix it
=============

There is nothing to change in your program to work around this. Please report it
at https://github.com/ironplc/ironplc/issues, including the program in the editor
and the playground version shown in the interface, so the maintainers can
reproduce the failing write path.
