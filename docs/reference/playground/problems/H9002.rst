=====
H9002
=====

.. problem-summary:: H9002

A request to advance the program by one or more scan cycles arrived before any
program had been loaded into a stepping session, so there was nothing to run.

The playground's step-through debugger has a two-phase contract: the front end
first calls ``load_program`` to compile the source and create a session, and
only then calls ``step`` to execute scan cycles against it. This error means a
``step`` call was made while no session existed — either before the first
``load_program`` or after the session was cleared by ``reset_session``.

When this happens
=================

This is an **internal error** that reflects a contract violation between the
playground front end and the WebAssembly module. During normal use the front end
always establishes a session before stepping, so you should never see it. It
indicates a bug in the playground's control flow — for example, a race where the
step control became active before loading finished, or stayed active after a
reset.

How to fix it
=============

Reload the page and run your program again, which re-establishes a clean session
before any stepping occurs. If the error keeps happening, please report it at
https://github.com/ironplc/ironplc/issues with the steps that led to it and the
playground version shown in the interface.
