=====
H1001
=====

.. problem-summary:: H1001

The playground was asked to run pre-compiled bytecode, but the text supplied in
place of that bytecode is not valid `base64 <https://en.wikipedia.org/wiki/Base64>`_.

The playground exchanges compiled programs as base64-encoded ``.iplc`` container
bytes. When you run a program, the editor first compiles your source to a
container and then hands the encoded bytes to the runtime. This error means the
decoder rejected those characters before any container could be read — the input
contains characters outside the base64 alphabet, or its length is not a valid
base64 length.

When this happens
=================

In normal use the playground produces the base64 itself, so this error should
not appear. It surfaces when a program is loaded from an external source that
carries a malformed value — most often a shared link whose bytecode parameter
was truncated or altered in transit, or a hand-edited URL.

How to fix it
=============

Re-generate the program from source rather than reusing the damaged encoded
value. Paste your IEC 61131-3 source into the editor and run it again; the
playground will compile and encode it fresh. If you followed a shared link, ask
whoever shared it to resend the full, unmodified URL.
