=====
P2032
=====

.. problem-summary:: P2032

This error occurs when a reference assignment has incompatible types. The reference type and the target type must match exactly, and a reference takes only ``REF()``, ``NULL`` or another reference.

Example
-------

The following code will generate error P2032:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           y : REF_TO REAL;
       END_VAR

       y := REF(x);  (* Error: REF_TO REAL cannot hold reference to INT *)
   END_PROGRAM

To fix this error, ensure the reference type matches the variable type:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           y : REF_TO INT;
       END_VAR

       y := REF(x);  (* Correct: REF_TO INT matches INT variable *)
   END_PROGRAM

A value that is not a reference
-------------------------------

The following code will generate error P2032:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           r : REF_TO INT;
       END_VAR

       r := 0;  (* Error: 0 is a number, not a reference *)
   END_PROGRAM

A reference holds where a variable is, so a number, or a variable of another
type, is not something it can hold. This applies to a CODESYS
``POINTER TO`` as well: ``p := 0`` is an error, in every dialect.

To fix this error, assign ``NULL`` for a reference that refers to nothing,
or the reference to a variable:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           r : REF_TO INT;
       END_VAR

       r := NULL;    (* Correct: refers to nothing *)
       r := REF(x);  (* Correct: refers to x *)
   END_PROGRAM

A reference to a reference
--------------------------

``REF()`` of a reference variable is a reference to a reference, and a
reference to a reference is not a reference to a value. Each level takes only
a reference to the type at that level, so the following code will generate
error P2032 twice:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           r : REF_TO INT;
           rr : REF_TO REF_TO INT;
       END_VAR

       r := REF(r);   (* Error: REF(r) is REF_TO REF_TO INT, r is REF_TO INT *)
       rr := REF(x);  (* Error: REF(x) is REF_TO INT, rr is REF_TO REF_TO INT *)
   END_PROGRAM

Had the first assignment been accepted, ``r`` would hold the location of
itself, and ``r^ := 5`` would then make ``r`` refer to whatever variable is at
location 5.

To fix this error, take the reference at the level the target expects:

.. code-block::

   PROGRAM Main
       VAR
           x : INT;
           r : REF_TO INT;
           rr : REF_TO REF_TO INT;
       END_VAR

       r := REF(x);   (* Correct: a reference to the INT *)
       rr := REF(r);  (* Correct: a reference to the reference *)
       rr^ := REF(x); (* Correct: stores a reference to an INT in r *)
   END_PROGRAM
