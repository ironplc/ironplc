=====
P4033
=====

.. problem-summary:: P4033

This error occurs when a source uses IEC 61131-3:2013 partial-access syntax
(``.%Xn``, ``.%Bn``, ``.%Wn``, ``.%Dn``, or ``.%Ln``) without enabling it.
Partial-access syntax is standardized in Edition 3 of IEC 61131-3 but is not
part of Edition 2, so it is gated behind the
``--allow-partial-access-syntax`` flag.

Example
-------

The following code will generate error P4033:

.. code-block::

   PROGRAM main
   VAR
       b : BYTE;
       r : BOOL;
   END_VAR
       r := b.%X0;
   END_PROGRAM

To fix this error, either use the Edition 2 short form ``.n``:

.. code-block::

   r := b.0;

Or enable partial-access syntax:

.. |flag| replace:: ``--allow-partial-access-syntax``
.. include:: /includes/enabled-by-flag.rst

Scope
-----

IEC 61131-3:2013 defines partial access at five granularities — ``.%Xn``
(bit), ``.%Bn`` (byte), ``.%Wn`` (word), ``.%Dn`` (double word), and
``.%Ln`` (long word). The flag enables all five forms, and all five raise
``P4033`` when the flag is off. Only the bit form has an Edition 2
equivalent (the ``.n`` short form); the wider forms have none, so a source
that uses them must enable the flag. See
:doc:`/reference/language/structured-text/bit-access` for the full feature
description.
