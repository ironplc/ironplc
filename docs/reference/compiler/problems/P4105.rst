=====
P4105
=====

.. problem-summary:: P4105

This error occurs when an enumerated value is written ``Type.value`` without
the ``--allow-dotted-enum-value`` compiler flag.

IEC 61131-3 writes a qualified enumerated value with a number sign,
``Type#value``. Writing it with a period, as TwinCAT and CODESYS do, is an
extension.

Example
-------

The following code will generate error P4105:

.. code-block::

   TYPE E_Blink : (off, slow, fast); END_TYPE

   PROGRAM main
   VAR
       state : E_Blink;
   END_VAR
       CASE state OF
           E_Blink.slow: ;
       END_CASE;
   END_PROGRAM

To fix this error, either use the standard spelling:

.. code-block::

   CASE state OF
       E_Blink#slow: ;
   END_CASE;

Or enable the extension:

.. |flag| replace:: ``--allow-dotted-enum-value``
