=====
V6011
=====

.. problem-summary:: V6011

The Debug Adapter Protocol ``launch`` request included a ``scanLimit`` that is
not a whole number of at least one scan cycle. The debug server rejects the
request before it loads the program, so the session does not start.

``scanLimit`` bounds a debug run. A PLC program does not finish on its own, so
a session with no breakpoint scans until something stops it; ``scanLimit``
gives that run a ceiling, which is useful when a program loops away without
reaching the line you wanted to inspect.

Why Zero Is Rejected
--------------------

There is no value of ``scanLimit`` that means "unlimited". An unbounded run is
requested by leaving the setting out of the launch configuration entirely.

``0`` and ``-1`` are both conventional ways to spell "no limit" in other
tools, so it is tempting to write one of them here. Neither works, and they
are rejected rather than quietly reinterpreted. Read literally, a limit of
zero asks the debugger to run no scan cycles at all, which it cannot do: the
bound is tested after a cycle completes, so the shortest run it can produce is
one cycle. A negative count of scan cycles has no reading at all.

Example
-------

The following launch configuration produces error V6011:

.. code-block:: json
   :caption: .vscode/launch.json

   {
     "type": "ironplc",
     "request": "launch",
     "name": "IronPLC: Debug Active File",
     "program": "${file}",
     "scanLimit": 0
   }

Deleting the ``scanLimit`` line fixes it, and is how an unbounded run is
requested: the session then scans until you stop it or a breakpoint pauses it.

To stop after a fixed number of cycles instead, give the count you want:

.. code-block:: json

   "scanLimit": 1

Solutions
---------

1. Remove ``scanLimit`` from the launch configuration to run until you stop the session
2. Set ``scanLimit`` to the number of scan cycles you want to run, which must be ``1`` or more
3. Replace a fractional value such as ``1.5`` with a whole number of cycles
4. Set a breakpoint instead of a scan bound when you want the session to stop at a particular line
