# Compatibility Library Authoring Policy

See [specs/steering/compatibility-library-authoring.md](../../specs/steering/compatibility-library-authoring.md) for the full policy.

This file governs how compatibility libraries (bundled vendor-compatibility declarations) are authored — risk tiers, allowed/forbidden inputs, the clean-room-with-AI workflow, and how the policy is enforced — so that distributing them, including AI-generated shims, does not create copyright or license problems.
